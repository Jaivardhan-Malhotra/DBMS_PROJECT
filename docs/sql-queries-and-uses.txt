CREATE VIEW v_match_details AS
SELECT match_id, match_date, match_time, match_type, status,
       season_year, venue_name, team1_name, team2_name,
       winner_name, player_of_match_name
FROM matches
JOIN seasons ON matches.season_id = seasons.season_id
JOIN venues ON matches.venue_id = venues.venue_id
JOIN teams AS team1 ON matches.team1_id = team1.team_id
JOIN teams AS team2 ON matches.team2_id = team2.team_id
LEFT JOIN teams AS winner ON matches.winner_id = winner.team_id
LEFT JOIN players ON matches.player_of_match = players.player_id;
Use: Provide joined names and details for match displays.
Used in: database/schema.sql; server/src/controllers/matchesController.js

PLAYER STATISTICS

SELECT player and team details,
       COUNT(player_match.id), COUNT(DISTINCT player_match.match_id),
       SUM(player_match.runs_scored), SUM(player_match.wickets_taken),
       SUM(player_match.balls_faced), SUM(player_match.is_out),
       player profile totals
FROM players
LEFT JOIN teams ON teams.team_id = players.team_id
LEFT JOIN player_match ON player_match.player_id = players.player_id
GROUP BY player;
Use: Calculate career totals and batting metrics from match records, using profile totals when there are no recorded match rows.
Used in: GET /api/player-statistics; playerStatisticsController.getPlayerStatistics()
